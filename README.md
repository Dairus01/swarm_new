# Swarm Subnet 124 - Drone Flight Controller

Autonomous drone navigation model for Bittensor Subnet 124 (Swarm).

## Model

Heuristic state-machine controller. No ML inference, no GPU required.

**Dependencies:** Python 3.10+, NumPy, SciPy

## Submission

`submission.zip` contains:
- `drone_agent.py` — flight controller with `DroneFlightController` class
- `ppo_policy.zip` — placeholder (required by submission format, not used at runtime)
